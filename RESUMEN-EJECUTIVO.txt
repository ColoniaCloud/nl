================================================================================
                           🎓 KEY LEARNINGS
================================================================================

1. INCREMENTAL > DISRUPTIVE
   → Built in 2 phases with clear dependencies
   → Each phase tested independent of next
   → Rollback is trivial at any point

2. AUTOMATION PREVENTS DISASTER
   → Manual backups = forgotten backups
   → Cron + alerting = reliable safety net
   → Tested restore = provable recovery

3. DOCUMENTATION > TRIBAL KNOWLEDGE
   → Next operator can run these procedures
   → Team can onboard anyone with tests
   → Audit trail matches source control

4. LOCAL + REMOTE = BEST PRACTICE
   → Local for speed (15 min RTO)
   → Remote for safety (AWS S3 resilience)
   → Costs practically nothing ($0.22/month)

5. SECURITY ISN'T OPTIONAL
   → Hardcoded secrets = guaranteed breach (when, not if)
   → Proper perms (600) + externalization = production-grade
   → Rotation prevents credential staleness
